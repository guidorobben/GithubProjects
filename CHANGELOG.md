# Changelog

2026-10-20 — Base URLs and tokens
Users can register GitHub and Azure DevOps base URLs, each with its own personal access token that is stored securely, can never be read back, and is removed after an environment copy.

2026-10-20 — GitHub repositories
Users maintain GitHub owners (users and organizations, each of which can be set to Ignore) and retrieve their repositories on demand, including the token user's private ones; repositories that GitHub no longer returns are removed.
